# 📚 NFLibrary

**NFLibrary**는 JSP/Servlet 기반의 도서관 웹 애플리케이션입니다.  
도서 검색과 대출/반납, 희망도서 신청, 공지사항, 회원 관리 기능을 제공하며,  
DAO–Service–Controller의 MVC 아키텍처로 구현되었습니다.

---

## 🚀 주요 기능
- **도서 관리**
  - 도서 검색 및 상세 조회
  - 대출, 반납, 희망도서 신청
- **회원 관리**
  - 회원가입, 로그인/로그아웃
  - 마이페이지(정보 수정, 탈퇴, 대출 내역 확인)
- **공지사항**
  - 공지사항 등록, 수정, 삭제, 조회
- **공통**
  - 에러 처리 페이지
  - 공통 레이아웃(header/footer)

---

## 🛠 기술 스택
- **Language**: Java
- **Web**: JSP, Servlet
- **Server**: Apache Tomcat 11
- **DB**: Oracle (JDBC Template 이용)
- **Build/IDE**: Eclipse (Dynamic Web Project)

## 📚 KH Library – JSP/Servlet
- 회원가입/로그인, 마이페이지, 희망도서(위시북) 조회, 계정삭제 흐름을 JSP · Servlet · JSTL로 구현했습니다.
Servlet (Controller) <br>
  ↓ <br>
Service <br>
  ↓ <br>
DAO (JDBC) <br>
  ↓ <br>
DB <br>
  ↑ <br>
JSP(View)  ←  forward by Controller <br>
이 순서대로 구현하였습니다.

## 소감
신선호 - 팀장역할이자 프로젝트에 책임에 크게 기여못한것 같아 죄송한 마음이고, 
한 프로젝트의 각 파트 분배 및 소통에 있어 잘 해결하지 못한것 같아 아쉬웠습니다.
DB수정 및 추가 프로젝트 추가 및 수정에 있어 원할한 소통이 되지 못한것 같아 너무 아쉬웠습니다 
그러다 보니 이도저도 아니게 같은 방향으로 나아가야 할것이 여럿이 제각각 자기만의 길로 나아가는 느낌이라 
어려웠습니다. 기준점을 정하고 구현을 해야했는데 각자 소통을 안하니 프로젝트를 진행하는데 있어 너무 힘들었습니다
그리고 코드작성을 할때 다들 무분별한 AI코드로 구성되어 있어 통일하여 만들기 어려웠으며 주석이 달려있지 않아 무엇이 무엇인지 찾는데 시간과 이해가 너무 오래 걸렸습니다.
이번 프로젝트로 인해 책임감, 의사소통, 기준점, 통일성에 대해 크게 느끼게 되었으며 
여태까지의 자기 자신에 대해서 반성및 부족한 점에 대해 잘 느끼게 된 경험이 큰것 같습니다.
